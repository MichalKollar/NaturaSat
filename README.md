NaturaSat_v2.1.6

The minimum software and hardware requirements are as follows:

-Operating system: x64-based version of Windows 10 and higher; Recommended: Windows 11
-Minimum CPU or processor speed: Intel or AMD processor with 64-bit support; Recommended: 2.2 GHz or higher, Multicore
-Memory/RAM: 8GB or higher
-Screen resolution: 1024x768px or higher, Recommended: 1920x1080px
-Free space: 100 MB of free space + space for downloaded datasets

In this folder, you will find a folder named NaturaSat_v2.1.6 
and a file called VC_redist.x64.exe.

First, run and install the Microsoft Visual C++ 2015-2022 Redistribution libraries from the file VC_redist.x64.exe. 
(There is a possibility that this library is already installed on your computer, and the installation will notify you about it.)

Then, you can run NaturaSat_v2.1.6.exe or NaturaSat-Historic_v2.1.6.exe located in the NaturaSat_v2.1.6 folder.

To use the application, you need to activate it. 
Please send us the request key, which will be displayed in a dialog window after the first start of the application. 
Once we receive the request key, we will send you the activation key, which will activate the application only on your computer in the current user profile.
